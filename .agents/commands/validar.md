# /validar

Validar uma alegação de conclusão ou o estado final de uma mudança.

## Exemplos de claims

- "bug corrigido";
- "deploy agora funciona";
- "consumo de memória caiu";
- "contrato preservado";
- "migração é segura".

Para cada claim, associar evidência e classificar como:

`VERIFICADO`, `PARCIALMENTE_VERIFICADO`, `NAO_VERIFICADO` ou `BLOQUEADO`.

Resultado anterior à última edição não comprova o estado final. Ausência de erro também não prova comportamento sem relação causal explícita.
