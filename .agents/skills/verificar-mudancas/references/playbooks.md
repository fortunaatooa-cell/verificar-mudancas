# Playbooks resumidos
Bug: esperado/observado → reprodução/evidência → hipóteses → teste/prova → menor correção → regressão → review → verificação.
Feature: aceite → contratos → plano → provas → implementação → integração → review → rollout.
Refatoração: baseline → comportamento protegido → mudança estrutural → regressão.
Migração: atual/alvo → compatibilidade → coexistência → migração/backfill → reconciliação → recuperação.
Incidente: impacto → evidência → contenção reversível → hipótese → experimento → recuperação → observação → lição.
Performance: baseline → métrica → profile/telemetria → hipótese → benchmark → correção → comparação final.
