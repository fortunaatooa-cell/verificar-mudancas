# APIs, dados, distribuídos e cloud
APIs: método, path, status, headers, schema, erros, versionamento, compatibilidade, consumidor real.
Dados: schema, constraints, índices, transações, locks, migração, backfill, replay, reconciliação.
Distribuídos: duplicidade, ordem, at-least-once, idempotência, retries, DLQ, consistência eventual e falha parcial.
Cloud/IaC: conta, região, workspace, target, permissões, plan/diff, replacement/destruição e smoke autorizado.
CI/CD: branch, artifact, ambiente, config/secrets e verificação pós-deploy.
