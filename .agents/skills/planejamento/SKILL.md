# Planejamento

Use para feature ampla, migração, mudança multi-componente, trabalho com dependências ou pedido explícito de plano. Defina objetivo, desconhecidos, ordem, critérios observáveis, prova e risco. Não implemente quando o pedido for somente planejamento.
