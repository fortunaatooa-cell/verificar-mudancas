# Estratégia de testes
Mapeie propriedade para prova: unitário, integração, contract, banco, E2E, infra plan/smoke, benchmark, runtime measurement ou teste negativo.
TDD real = RED → GREEN → REFACTOR → REGRESSION.
RED precisa falhar pelo motivo correto. Setup/sintaxe/dependência alheia não conta.
Teste escrito depois da implementação é regressão, não RED histórico.
