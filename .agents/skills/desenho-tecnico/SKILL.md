# Desenho técnico
Identifique tipo/finalidade, revisão, escala/unidade, legenda, vistas, componentes, IDs, conexões, fluxo, interfaces, dimensões e notas.
Separe OBSERVADO, INFERIDO e NÃO DETERMINÁVEL.
Nunca invente cota, tolerância, material ou norma.
Faça cross-check com implementação quando disponível.
Para criar, prefira Mermaid/PlantUML/DOT/SVG; CAD/script apenas com dados suficientes.
