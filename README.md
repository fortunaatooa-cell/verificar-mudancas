# Copilot 365 — pacote pronto para instalação

Use estes arquivos:

1. `verificar-mudancas-copilot365-agentic-engineering-v3.2.zip` — envie este arquivo em **Carregar habilidade**.
2. `INSTRUCOES-AGENTE-COPILOT365.txt` — abra, copie todo o conteúdo e cole no campo **Instruções** do agente.
3. `PACKAGE_SHA256.txt` — checksum do ZIP.

## Importante

Não use o botão **Download ZIP** da branch e tente enviar o ZIP da branch inteira ao Agent Builder. Esse arquivo da branch contém o repositório e pode incluir vários `SKILL.md`.

O ZIP correto acima foi validado com **exatamente 1 `SKILL.md`**.
